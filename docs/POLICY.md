# 一人公司政策机会解读：数据与产品设计

## 1. 先区分“新闻”和“政策”

现有新华网/中国新闻网解决的是“知道发生了什么”，不能直接回答“我能不能拿到补贴”。

真正影响一人公司的信息有四类：

| 类型 | 典型内容 | 价值 |
|---|---|---|
| 政策原文 | 国务院/部委/地方政府文件 | 判断方向、适用对象、支持方式 |
| 申报通知 | 某区某局开始受理、截止日期、材料清单 | 决定“现在能不能报” |
| 公示名单 | 拟支持企业、补贴金额 | 判断门槛与真实力度 |
| 政策解读 | 官方问答、操作指南 | 降低理解成本 |

只有“最新政策”列表是不够的；最有价值的是**申报通知 + 截止日期 + 申报入口 + 适用对象 + 金额/上限**。

## 2. 已接入的政策源

2026-11-18 新增：

```text
site_id: gov_cn
name: 中国政府网
channel: latest_policy（最新政策）
URL: https://www.gov.cn/zhengce/zuixin/
discovery: ZUIXINZHENGCE.json（官方静态 JSON）
```

已验证 2/2 样本正文成功，当前采集 20 条最新政策。

但要注意：

- 这是**国家层面的政策原文**，很多是法律、条例、意见，不是直接申报通知；
- 一条“补贴”关键词命中，不代表一人公司能申请；
- 真正的补贴通常在**市/区/园区**的工信、科技、人社、税务、市场监管部门发布；
- 国家政策只是“上位依据”，地方才有申报窗口和金额。

## 3. 还应该接什么

按优先级：

### A. 国家部委

- 国家发展改革委
- 工业和信息化部（专精特新、中小企业、数字化转型）
- 财政部（补贴、政府采购）
- 国家税务总局（小微、个体、研发加计扣除）
- 科技部（科技型中小企业、创新基金）
- 人社部（创业担保贷款、社保补贴、培训补贴）
- 市场监管总局（个体工商户、登记、资质）

### B. 地方（最关键）

以公司注册/经营地为准：

- 市/区人民政府“政策文件”
- 市/区工信局（专精特新、技术改造、数字化）
- 科技局（科技型中小企业、研发补助、高企）
- 人社局（一次性创业补贴、社保补贴、创业担保贷款）
- 税务局（小微税收优惠）
- 市场监管局（个体/小微企业）
- 园区/孵化器（房租、人才、落地奖励）

> 不同城市差异极大。没有“注册地 + 行业”，无法给出可靠的补贴清单。

### C. 申报/公示

- 区级“申报通知”
- “拟支持名单/公示”
- “资金拨付”
- 政府购买服务/采购公告

这些比新闻更接近“钱在哪里”。

## 4. 一人公司真正值得关注的政策类型

### 税收

- 小规模纳税人增值税优惠
- 小型微利企业所得税优惠
- 研发费用加计扣除
- “六税两费”减半
- 个体/小微相关优惠

### 补贴

- 一次性创业补贴
- 创业担保贷款贴息
- 社保补贴
- 场地租金补贴
- 培训补贴
- 研发/科技型中小企业补助
- 数字化改造补贴

### 资质与订单

- 科技型中小企业
- 创新型中小企业
- 政府采购/国企采购
- 平台/园区入驻
- 知识产权、软件著作权、资质认证

### 融资

- 创业担保贷款
- 科技信用贷
- 知识产权质押
- 园区/政府引导基金

不要默认“专精特新”适合一人公司；它通常有营收、研发、知识产权、年限等门槛，只能作为中长期目标，不是当前补贴。

## 5. 需要的结构化字段

每篇政策应尽量提取：

```text
政策名称
发布机关
文号
发布日期
生效日期
适用地区
适用行业
适用对象（个体/小微/一人有限公司/科技型等）
支持方式（补贴/税收/贷款/采购/资质/租金/人才）
金额或上限
申报截止日期
申报入口 URL
申请材料
政策依据原文句子
状态（可申报/观察/不适用/已截止）
```

## 6. 匹配逻辑

输入一人公司画像：

```text
注册地/经营地
行业与产品
企业类型（一人有限公司/个体/个人独资）
成立时间
员工人数
年营收
是否纳税/社保
研发投入/知识产权
场地（园区/自有/租赁）
目标（补贴/税收/融资/资质/订单）
```

输出三档：

- **可申报**：满足硬条件，有截止日期和入口；
- **观察**：方向相关，但当年通知未出或门槛差距可补；
- **不适用**：明确不满足，避免浪费时间。

每条结论必须附原文链接和依据句，不能只给“建议申请”。

## 7. 当前 MCP 能做什么、不能做什么

已经能做：

- 采集中国政府网最新政策；
- 本地搜索关键词、按日期/站点过滤；
- 读取政策原文全文；
- 保留原文 URL、发布时间、抓取时间；
- 跨站检索（新华网/中国新闻网/中国政府网）。

还不能自动做：

- 判断“是否真的适合你”；
- 自动识别申报截止日期和金额；
- 自动匹配企业画像；
- 覆盖地方区级申报通知；
- 替代官方政策解释。

这些需要继续加数据源和结构化字段，不能靠“搜索关键词 + 大模型自由发挥”。

## 8. 下一步需要你确认

为了给出一人公司的具体政策机会，请提供：

1. 注册/经营城市 + 区（例如“深圳南山”“杭州余杭”）；
2. 行业/产品/客户（To B / To C）；
3. 企业类型（一人有限公司/个体/个人独资）；
4. 最关心：补贴、税收、社保、房租、研发、资质、订单、融资中的哪几类；
5. 可选：成立时间、年营收、员工数、知识产权、是否在园区。

有了这 5 项，才能决定下一批接入哪些地方官方源，并把“政策列表”变成“可申报机会清单”。
